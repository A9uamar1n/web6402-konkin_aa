# Лабораторная работа №2

**Тема:** «Chronos Tours» — сайт туристического агентства путешествий во времени.

**Страницы** (папка `lab2/`):
- `index.html` — главная: приветствие, цитата Рэя Брэдбери, карточки преимуществ;
- `tours.html` — каталог эпох: таблица маршрутов с уровнем риска и стоимостью;
- `safety.html` — памятка хрононавта: изображение, правила безопасности, контакты.

**HTML:** блочные (`header`, `main`, `section`, `blockquote`, `table`) и строчные (`em`, `strong`, `span`, `small`, `cite`) элементы, ссылки (меню, `mailto:`, `tel:`), изображение, таблица.

**CSS** (отдельный файл `style.css`):
- селекторы: по тегу (`body`, `h1`, `p`), по классу (`.tour-table`, `.risk-badge`, `.warning-box`), по ID (`#main-terminal`, `#timeline-nav`), псевдокласс (`.nav-link:hover`);
- выравнивание в таблице: по левому краю, по центру и по правому краю;
- тёмная палитра с янтарным акцентом;
- без испольхования сторонних библиотек.

# Лабораторная работа №3

**Тема:** «Core JavaScript» — набор функций на чистом JavaScript, решения проверяются автоматическими тестами.

**Файлы** (папка `lab3/`):
- `src/core.js` — решения десяти заданий;
- `src/core.spec.js` — тесты на `mocha` (`assert`);
- `package.json` — скрипты `test`, `prettier`, `prettier:check`; зависимости `mocha`, `prettier`, `lint-staged`.

**Задания:**
- `isInteger` — проверка на целое число через побитовые операторы;
- `even` — массив чётных чисел от 2 до 20;
- `sumTo` / `recSumTo` — сумма чисел до `n` циклом и рекурсией;
- `factorial` — факториал `n`;
- `isBinary` — проверка, что число является степенью двойки (`n & (n - 1)`);
- `fibonacci` — `n`-е число Фибоначчи без рекурсии;
- `getOperationFn` — замыкание: хранит значение и применяет к нему переданную операцию при каждом вызове;
- `sequence` — генератор арифметической последовательности с независимым состоянием у каждого экземпляра;
- `deepEqual` — рекурсивное сравнение объектов по содержимому.
